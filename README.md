# Smart Store Pilot

necesito tu ayuda para crear un prototipo de tienda tipo minimarket local, la idea de la pagina es que sea usada solamente por los empleados del local y no por los clientes, facilitando el cobro de los productos y el inventario de la tienda. la pagina debe tener un carrito en el cual sume el total de una venta, guarde el total de ventas del dia para un reporte y una opcion para editar el stock del inventario
